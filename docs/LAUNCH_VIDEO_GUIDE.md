# Validuct Launch Video Guide

> **Duration:** 90 seconds (1.5 mins)
> **Tools:** Cursorful (recording), Canva (editing)
> **Format:** 16:9 (YouTube/Twitter/LinkedIn) or 9:16 (TikTok/Reels)

---

## Video Structure Overview

| Section | Duration | Purpose |
|---------|----------|---------|
| Hook | 0-8 sec | Grab attention with pain point |
| Problem | 8-22 sec | Show current broken solutions |
| Solution Intro | 22-30 sec | Introduce Validuct |
| Demo: Submit Idea | 30-42 sec | Show ease of use |
| Demo: Validation Signals | 42-58 sec | Core value prop |
| Demo: Feedback | 58-70 sec | Organized comments |
| Demo: Validation Summary | 70-80 sec | Dashboard/profile |
| CTA | 80-90 sec | Drive signups |

## Demo Data to Prepare

### Sample Idea to Submit (During Recording)

```
Heading: "AI tool that turns voice notes into structured meeting summaries"

Description: "Record your meetings or voice memos, and get clean summaries
with action items, decisions, and follow-ups extracted automatically.
Integrates with Notion and Slack."
```

### Pre-populated Idea (For Signals Demo)

Create an idea beforehand with:

- **12+** "Would Pay" signals
- **15+** "Problem Real" signals
- **8+** "Ready to Build" signals
- **2-3** "Needs Clarity" signals

### Sample Comments to Add

| Category | Comment |
|----------|---------|
| Problem Clarity | "Love this — I waste 30 mins after every call writing notes" |
| Target Users | "This would crush it with sales teams and consultants" |
| Willingness to Pay | "I'd pay $15/mo for this easily" |
| Feature Suggestions | "Integration with Google Meet would be huge" |

## Recording Checklist

### Browser Setup
- [ ] Hide bookmarks bar
- [ ] Remove/hide browser extensions
- [ ] Use incognito or fresh profile
- [ ] Clear any notifications

### App Setup
- [ ] Demo idea created with realistic signals
- [ ] Sample comments added across categories
- [ ] Profile has validation summary data
- [ ] App is deployed/running smoothly

### Cursorful Setup
- [ ] Cursorful extension enabled
- [ ] Smooth cursor trail configured
- [ ] Test recording before final take

### Screen Settings
- [ ] Resolution: 1920x1080 (horizontal) or 1080x1920 (vertical)
- [ ] Clean desktop (if visible)
- [ ] Do Not Disturb mode enabled

---

## Recording Tips

1. **Record each scene separately** — Easier to edit in Canva
2. **Slow cursor movements** — Cursorful highlights cursor, be deliberate
3. **Zoom in** on key interactions (signals buttons, feedback categories)
4. **Pause briefly** on important UI elements
5. **Do 2-3 takes** of each scene, pick the best
