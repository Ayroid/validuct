# VALIDUCT

**Validate your ideas to create successful products**

## Overview

VALIDUCT is a community-driven platform designed to help innovators and entrepreneurs validate their product ideas before investing significant time and resources. Users can share their ideas, gather valuable feedback through comments and votes, and track their journey from concept to launch.

## What is VALIDUCT?

VALIDUCT bridges the gap between ideation and execution by creating a collaborative space where:

- **Creators** can share their product ideas and receive honest feedback from the community
- **Validators** can discover innovative ideas, provide constructive criticism, and support promising concepts
- **Everyone** benefits from transparent idea validation, reducing the risk of building products nobody wants

## Key Features

### 🚀 Idea Management
- Create, read, update, and delete your ideas
- Organize ideas with clear headings and detailed descriptions
- Track idea status: **Validated**, **In Progress (WIP)**, or **Launched**
- Attach links to validated or launched products

### 👥 Community Engagement
- Upvote and downvote ideas to show support or concerns
- Comment on ideas with nested replies for in-depth discussions
- View comment counts and engagement metrics

### 📊 Discovery Timelines
- **HOT**: Most upvoted ideas in the last 24 hours
- **NEW**: Latest ideas submitted to the platform
- **TRENDING**: All-time top-ranked ideas

### 👤 User Profiles
- Personalized profiles with unique usernames and profile pictures
- View all ideas by a specific user, ordered from newest to oldest
- Pin up to 5 favorite ideas for quick access

## Tech Stack

- **Frontend**: Next.js (React framework)
- **Backend**: Node.js with Express
- **Database**: TBD based on development plan

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/Ayroid/Validuct.git
cd Validuct
```

2. Install frontend dependencies
```bash
cd frontend
npm install
```

3. Install backend dependencies
```bash
cd ../backend
npm install
```

4. Configure environment variables (see `.env.example` in each directory)

5. Run the development servers

**Frontend:**
```bash
cd frontend
npm run dev
```

**Backend:**
```bash
cd backend
npm run dev
```
