# VALIDUCT

**Stop guessing. Start validating.**

> AI-powered idea validation platform that gives builders evidence, not just opinions.

## Overview

VALIDUCT is a validation intelligence platform that helps entrepreneurs and builders validate their product ideas with AI analysis, community feedback, and real purchase signals — before investing significant time and resources.

Unlike traditional forums where you just get opinions, VALIDUCT provides **actionable intelligence**: AI-generated competitor analysis, structured validation frameworks, and real demand signals from potential customers.

## Why VALIDUCT?

| Platform | What It Offers | What It Lacks |
|----------|----------------|---------------|
| Product Hunt | Launch showcase | Pre-launch validation, actionable feedback |
| Reddit | Discussion | Structure, data, follow-through tracking |
| Indie Hackers | Community stories | Systematic validation framework |
| Twitter/X | Viral reach | Depth, organized feedback, persistence |

**VALIDUCT fills the gap:** Structured validation with actionable intelligence, not just opinions.

## Key Features

### 🤖 AI-Powered Analysis
- Instant competitor landscape analysis on idea submission
- Market trend insights and positioning suggestions
- Automated red flag detection (unclear revenue model, broad targeting)

### 📊 Structured Validation
- Multi-dimensional feedback (problem clarity, willingness to pay, differentiation)
- Expert-weighted feedback from verified industry professionals
- Real purchase intent signals, not just upvotes

### 🚀 Idea Lifecycle Tracking
- Track your idea from Draft → Validating → Building → Launched
- Collect waitlist signups and gauge price sensitivity
- Build case studies from validation to successful launch

### 👥 Community Engagement
- Upvote and downvote ideas to show support or concerns
- Comment on ideas with nested replies for in-depth discussions
- View comment counts and engagement metrics

### 📈 Discovery Timelines
- **NEW**: Latest ideas submitted to the platform
- **TRENDING**: Most upvoted ideas in the last 24 hours
- **TOP**: All-time top-ranked ideas

### 👤 User Profiles
- Personalized profiles with unique usernames and profile pictures
- View all ideas by a specific user, ordered from newest to oldest
- Pin up to 5 favorite ideas for quick access

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/Ayroid/Validuct.git
cd Validuct
```

2. Install frontend dependencies
```bash
cd frontend
npm install
```

3. Install backend dependencies
```bash
cd ../backend
npm install
```

4. Configure environment variables (see `.env.example` in each directory)

5. Run the development servers

**Frontend:**
```bash
cd frontend
npm run dev
```

**Backend:**
```bash
cd backend
npm run dev
```
